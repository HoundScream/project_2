## Implementation Summary
- Decisions:
  - Модуль 2.1 встроен в поток кабинета перед созданием `business_profiles` и `analysis_requests`, чтобы ошибка останавливала сценарий до записи нового запроса.
  - Ошибки разделены на продуктовые причины: неверная ссылка, недоступная карточка, временная недоступность источника, исчерпанный лимит и дубль карточки в истории пользователя.
  - Для проверки внешнего источника добавлен HTTP-валидатор, который различает `404/410`, `429/403/5xx`, таймауты и часть характерных текстовых маркеров страницы.
  - Для paywall-сценария добавлен целевой экран `/pricing` с CTA `Оплатить PRO` и пакетом `3 запроса + анализ 5 конкурентов`.
- Changes:
  - Cargo.toml: добавлена зависимость `reqwest` для проверки доступности карточки по внешнему URL.
  - src/main.rs: добавлены `ValidationIssue`, серверные проверки дублей и доступности источника, новый UI-блок `Модуль 2.1. Validation / Error Handler`, маршрут `/pricing` и экран пакета `PRO`.

## Goal
- Реализовать модуль 4.2: отдельный экран статуса анализа после нажатия кнопки `Анализировать`, связанный с `analysis_requests` и историей кабинета.

## Input Context

- Related files: src/main.rs, deploy/stages/2026-05-21-stage-04-1-free-cabinet.md

## Implementation Summary
- Decisions:
  - После отправки ссылки пользователь больше не возвращается сразу в кабинет, а попадает на отдельный маршрут статуса `/cabinet/{user_id}/analysis/{request_id}`.
  - Лишние действия убраны из сценария: нет ручного сохранения результата, нет изменения ссылки, нет повторного запуска и просмотра технических деталей из экрана статуса.
  - Результат считается автоматически сохранённым в кабинете пользователя, а сам экран 4.2 показывает пошаговый прогресс и итоговое состояние.
  - Для текущего demo-stage статус анализа синхронизируется сервером по времени жизни запроса: `processing -> completed`, параллельно обновляется `ingestion_status` бизнес-профиля.
- Changes:
  - src/main.rs: добавлен маршрут страницы статуса анализа, новый UI экрана 4.2, синхронизация demo-статуса анализа, переход с формы кабинета на экран статуса и обновлённые тексты кабинета.
